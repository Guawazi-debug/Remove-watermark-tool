# TabBar 图标资源

请在此目录放置以下8个PNG图标文件：

| 文件名 | 说明 | 建议尺寸 |
|--------|------|----------|
| home.png | 首页-未选中 | 81×81 px |
| home-active.png | 首页-选中 | 81×81 px |
| category.png | 分类-未选中 | 81×81 px |
| category-active.png | 分类-选中 | 81×81 px |
| favorite.png | 收藏-未选中 | 81×81 px |
| favorite-active.png | 收藏-选中 | 81×81 px |
| profile.png | 我的-未选中 | 81×81 px |
| profile-active.png | 我的-选中 | 81×81 px |

## 图标风格要求

- 线条风格（类似下方参考）
- 未选中状态：灰色 #999999
- 选中状态：主题色 #d36b4c
- 透明背景 PNG
