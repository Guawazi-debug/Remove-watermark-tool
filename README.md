# 工具小栈 - 微信小程序

一款集合 30+ 实用小工具的微信小程序工具箱，覆盖文本处理、编码转换、开发辅助、计算与生活等场景，开箱即用。

## 功能特性

### 工具箱

| 分类 | 工具 |
|------|------|
| **媒体工具** | 视频解析（去水印下载） |
| **文本处理** | JSON 解析、JSON 生成、Base64、URL 编解码、文本对比、字数统计、正则测试、大小写转换、文本替换、文本去重、Unicode、HTML 转义 |
| **编码与安全** | MD5/SHA 哈希、JWT 解析、UUID 生成 |
| **开发辅助** | 时间戳转换、颜色转换、密码生成、JSON 对比、Cron 表达式、CSS 单位转换、代码格式化 |
| **计算与生活** | 进制转换、单位转换、计算器、日期计算、年龄计算、BMI 计算、个税计算、贷款计算 |

### 首页功能

- **工具搜索**：实时关键词搜索，按名称、描述和关键词过滤
- **最近使用**：自动记录最近打开的 6 个工具，快速访问
- **优先入口**：精选高频工具快捷入口
- **分类浏览**：按能力域分组展示所有工具
- **分享功能**：支持分享给好友和分享到朋友圈

## 技术栈

- 微信小程序原生开发
- WXML + WXSS + JavaScript
- Skyline 渲染引擎 + glass-easel 组件框架
- 自定义导航栏组件

## 使用方法

### 前置条件

- 微信开发者工具
- 微信小程序 AppID

### 本地运行

1. 克隆项目
   ```bash
   git clone git@github.com:Guawazi-debug/Remove-watermark-tool.git
   ```

2. 复制配置文件并填入你的 AppID
   ```bash
   cp project.config.json.example project.config.json
   ```
   打开 `project.config.json`，将 `appid` 字段的值 `your-appid-here` 替换为你自己的微信小程序 AppID。

3. 在微信开发者工具中导入项目目录

4. 开始开发和调试

### 视频解析接口

项目使用外部视频解析接口，默认地址为 `https://qsy.awenz.cn/api.php`。如需更换，在 `pages/index/index.js` 中修改 `PARSE_API` 常量。

```
GET https://qsy.awenz.cn/api.php?url=视频链接
```

### 发布上线

1. 在微信公众平台后台配置服务器域名（request 合法域名）
2. 在微信开发者工具中点击「上传」
3. 在微信公众平台提交审核并发布

## 注意事项

- 视频下载功能受微信小程序域名白名单限制，第三方视频源可能无法直接下载，会自动降级为复制链接方案
- 真机调试时需在开发者工具中勾选「不校验合法域名」
- 发布前需在微信公众平台配置合法域名
